# playground · 快增绩练习场

这个仓库随便折腾，专门用来练手 Git / GitHub 协作流程。搞坏了也没关系——这正是它存在的意义。

## 练习任务（对应培训 Session A 动手环节）

1. `git clone` 本仓库到本地（或服务器上）
2. 开一个分支 `feat/你的名字`
3. 在 `members/` 下新建 `你的名字.md`，写三行自我介绍
4. commit（message 按 `类型: 干了什么` 规范）并 push
5. 开 PR，找一位队友 review 通过后 merge
6. 彩蛋任务：两人约好改同一行，制造一次 conflict 并解决它

## 规则

- main 分支已开保护：不经 PR + 至少 1 个 approve，物理上合不进去
- 除 `members/` 外想加什么目录都行，练分支、练冲突、练回滚，随意
